The Aproint Copilot CLI release host is GitHub Releases at `https://github.com/aproint/copilot-cli/releases`.

Release signature verification for this fork will use an Aproint-controlled signing key once the fork release pipeline publishes signed artifacts. Do not use the upstream Amazon ECS public key to verify Aproint fork releases; this fork is not affiliated with, endorsed by, or supported by Amazon Web Services.

Until a fork signing key is published, verify downloads by checking that the binary URL is under `https://github.com/aproint/copilot-cli/releases/` and by comparing checksums published with the corresponding release.
