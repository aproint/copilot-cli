# Fork Identity

This repository is the Aproint-maintained fork of AWS Copilot CLI. It preserves the Apache-2.0 license and Amazon copyright notices from the upstream project, but the fork is not affiliated with, endorsed by, or supported by Amazon Web Services.

## Public Identity

| Surface | Fork value |
| --- | --- |
| Binary name | `copilot` |
| Go module path | `github.com/aproint/copilot-cli` |
| GitHub org/repo | `aproint/copilot-cli` |
| Documentation URL | `https://aproint.github.io/copilot-cli/` |
| Release host | GitHub Releases at `https://github.com/aproint/copilot-cli/releases` |
| Homebrew strategy | `aproint/tap/copilot-cli`, published through `aproint/homebrew-tap` |

The binary name remains `copilot` to preserve existing command-line workflows. Distribution, documentation, release, and package paths must use Aproint-owned channels unless a reference is explicitly retained as historical attribution.
