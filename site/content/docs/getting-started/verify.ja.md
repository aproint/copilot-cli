Aproint Copilot CLI のリリースホストは `https://github.com/aproint/copilot-cli/releases` の GitHub Releases です。

このフォークのリリース署名検証は、フォークのリリースパイプラインが署名済みアーティファクトを公開した後、Aproint 管理の署名キーを使用します。Aproint フォークのリリース検証に、上流の Amazon ECS 公開キーを使用しないでください。このフォークは Amazon Web Services と提携しておらず、承認またはサポートもされていません。

フォークの署名キーが公開されるまでは、バイナリ URL が `https://github.com/aproint/copilot-cli/releases/` 配下であることと、対応するリリースで公開されたチェックサムを確認してください。
